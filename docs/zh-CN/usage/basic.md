# 用户使用指南

---

## 积分规则

积分是 TinyForum 社区的核心激励机制，通过积极贡献获取积分。

### 积分获取

| 行为 | 积分 | 说明 |
|------|------|------|
| 注册 | +0 | 初始积分 |
| 每日签到 | +1 ~ 5 | 连续签到有加成 |
| 发布帖子 | +10 | 原创内容奖励 |
| 发布文章 | +20 | 长文创作奖励 |
| 发布评论 | +3 | 参与讨论 |
| 帖子被点赞 | +2 | 内容质量认可 |
| 评论被点赞 | +1 | 评论质量认可 |
| 答案被采纳 | +悬赏分 | 问答悬赏积分 |
| 举报确认 | +5 | 社区治理贡献 |

### 积分消耗

| 行为 | 积分 | 说明 |
|------|------|------|
| 发布问答悬赏 | -悬赏分 | 创建悬赏帖 |
| 违规被处罚 | -10 ~ 100 | 根据违规严重程度 |

## 用户角色与权限

| 角色 | 积分要求 | 核心权限 |
|------|----------|----------|
| 游客 | — | 浏览公开内容 |
| 用户 | 注册即可 | 发帖、评论、点赞、关注 |
| 会员 | 100+ | 无额外功能（荣誉标识） |
| 版主 | 管理员任命 | 管理指定板块的内容 |
| 审核员 | 管理员任命 | 内容审核权限 |
| 管理员 | 超级管理员任命 | 全局管理权限 |
| 超级管理员 | 系统内置 | 唯一最高权限 |

## 常见操作

### 发帖

1. 进入目标板块
2. 点击"发帖"按钮
3. 选择帖子类型：普通帖 / 文章 / 问答
4. 填写标题和内容
5. 可选：添加标签、设置封面图
6. 点击"发布"

### 评论与回复

- **评论帖子**：在帖子底部输入框直接评论
- **回复评论**：点击评论下方的"回复"按钮
- **采纳答案**（问答帖）：帖主可采纳某条回答为最佳答案

### 关注

- **关注用户**：在用户主页点击"关注"
- **关注主题**：在主题页点击"关注"
- **取消关注**：再次点击即可取消

### 举报

- 在帖子或评论旁找到"举报"按钮
- 选择举报原因并提交
- 审核员会处理举报

### 版主申请

1. 进入目标板块
2. 点击"申请版主"
3. 填写申请理由
4. 等待管理员审批

## 界面说明

### 首页
展示最新帖子、热门帖子、活跃板块。

### 个人主页
- **我的帖子**：自己发布的帖子列表
- **我的评论**：历史评论记录
- **关注/粉丝**：社交关系
- **积分记录**：积分变动明细
- **通知中心**：系统通知和互动提醒

### 时间线
展示你和关注用户的最新动态，按时间排序。

---

## 通知类型

| 类型 | 说明 |
|------|------|
| 点赞通知 | 你发布的内容被点赞 |
| 评论通知 | 你的帖子收到新评论 |
| 关注通知 | 有人关注了你 |
| 采纳通知 | 你的回答被采纳为最佳答案 |
| 系统通知 | 管理员操作、警告等 |
| 举报结果 | 你的举报被处理 |

## 移动端适配

TinyForum 前端基于响应式设计，支持手机/平板/桌面端自适应布局。
