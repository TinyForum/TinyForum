# 产品风险提示

> TinyForum 目前处于 **开发阶段**，尚未经过全面的安全审计和生产环境大规模验证。

---

## 已知局限

### 数据隔离

当前 API 响应在某些场景下可能暴露比前端展示更多的数据字段。这是由于开发阶段优先实现业务功能，部分接口未严格按 VO 最小化原则裁剪字段。计划在后续版本中完善字段级数据隔离。

### 权限粒度

RBAC 权限系统（Casbin）的路由级权限控制尚未在所有路由上启用，部分接口仅通过角色硬编码判断权限。详见 [后端 AGENTS.md](https://github.com/caoyang2002/TinyForum/blob/main/backend/AGENTS.md) 中关于 CasbinAuth 的迁移计划。

### 并发安全

部分数据库操作在高并发场景下可能出现竞态条件（如积分扣减、点赞计数）。计划后续引入乐观锁机制。

### 插件系统

插件系统目前处于测试阶段，不建议在生产环境中启用不受信任的第三方插件。插件代码运行在页面上下文中，存在跨站脚本（XSS）风险。

---

## 使用建议

1. **生产部署前**：请自行进行安全评估和渗透测试
2. **配置安全**：务必修改所有默认密码和密钥（`config/private.yml`）
3. **HTTPS**：生产环境必须启用 HTTPS
4. **数据备份**：定期备份 PostgreSQL 数据库
5. **审计日志**：定期审查 `audit_logs` 表

---

如发现安全漏洞，请通过 GitHub Issues 或邮件联系项目维护者，**勿在公开 Issue 中披露安全漏洞细节**。
