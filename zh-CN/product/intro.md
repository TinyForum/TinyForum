# TinyForum 天方论坛

TinyForum 是一个开源的现代化论坛系统，采用 **Go (Gin + GORM) 后端 + Next.js 前端** 架构，支持插件化和机器人自动化。

---

## 核心特性

### 内容生态
- **多类型内容**：支持帖子（类微博）、文章（类公众号）、问答（类知乎）、主题讨论
- **富文本编辑器**：基于 Tiptap 的所见即所得编辑器，支持 Markdown
- **多板块管理**：层级板块结构，支持版主自治
- **标签系统**：灵活的标签分类与搜索

### 社交互动
- **评论与回复**：嵌套评论树，支持楼中楼
- **点赞系统**：帖子和评论点赞
- **关注体系**：用户关注 + 主题关注 + 时间线订阅
- **积分机制**：发帖/评论/被点赞获得积分，形成社区激励

### 内容安全
- **敏感词过滤**：DFA 算法 + LLM 复核双重保障
- **内容审核**：AI 辅助内容审核流程
- **行为风控**：IP/用户行为风险评分
- **限流控制**：基于 Redis 的接口级限流

### 权限体系
- **角色层级**：超级管理员 → 管理员 → 版主 → 审核员 → 会员 → 用户 → 游客
- **RBAC 权限**：基于 Casbin 的细粒度路由权限控制
- **版主自治**：板块级版主申请、审批、权限分配

### 自动化
- **Bot 机器人**：Lua 脚本机器人 + 零代码 Flow 引擎
- **定时任务**：Cron 表达式调度
- **事件驱动**：新帖/新评论/新注册时自动触发

### 扩展性
- **插件系统**：前端动态加载插件组件
- **国际化**：基于 next-intl 的中英文双语支持
- **API 文档**：Swagger 自动生成接口文档

## 快速体验

### Docker Compose（推荐）

```bash
git clone https://github.com/caoyang2002/TinyForum.git
cd TinyForum
cp .env.example .env
docker compose up -d
```

浏览器打开 `http://localhost:8080` 即可访问。

详见 [开发指南 - 快速开始](/zh-CN/dev/first)。
