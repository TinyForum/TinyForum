# 常见问题

---

## 为什么登录后无法访问后台管理页面？

管理员页面使用 JWT 进行认证。请确保：

1. 已使用**管理员账号**登录（普通用户无权限）
2. 浏览器未清除 Cookie
3. 访问路径为 `/admin` 而非 `/api/v1/admin`

默认超级管理员账号请在 `backend/config/private.yml` 中查看/修改：

```yaml
admin_user:
  username: admin
  password: admin123    # 请立即修改！
  email: admin@tinyforum.local
```

## 发帖后为什么在首页看不到？

1. **审核状态**：如果开启了内容审核，帖子需要审核通过后才公开可见
2. **板块筛选**：检查首页是否筛选了特定板块
3. **敏感词拦截**：帖子可能因包含敏感词被拦截，检查通知中心

---

## 为什么有些板块无法发帖？

1. 部分板块可能设置了**只读模式**
2. 你可能被禁言（检查通知）
3. 该板块可能只允许特定角色发帖

---

## 社区角色有什么区别？

```
超级管理员 → 管理员 → 版主 → 审核员 → 会员 → 用户 → 游客
```

- **超级管理员**：系统唯一最高权限者，能管理所有内容、用户和配置
- **管理员**：全局管理权限，但不能修改超级管理员
- **版主**：管理指定板块内的内容和用户
- **审核员**：具有内容审核权限
- **会员**：积分 >= 100 的活跃用户（荣誉标识）
- **用户**：已注册的普通用户
- **游客**：未登录用户，仅可浏览

## 积分有什么用？如何获取？

积分体现用户在社区的贡献度：

- 发表优质内容获得积分
- 回答被采纳获得悬赏积分
- 积分影响排行榜排名
- 创建问答帖时可设置积分悬赏

详见 [积分规则](/zh-CN/usage/basic)。

## 如何成为版主？

1. 在目标板块点击"申请版主"
2. 填写申请理由
3. 等待管理员审批
4. 批准后即可获得该板块的管理权限

---

## 忘记密码怎么办？

如果你已配置邮件服务（SMTP），可通过登录页的"忘记密码"通过邮箱重置密码。

如使用 Docker Compose 部署且未配置邮件服务，请联系管理员手动重置。

---

## 如何配置邮件服务？

编辑 `backend/config/private.yml`：

```yaml
email:
  smtp_host: smtp.example.com
  smtp_port: 587
  username: your_email@example.com
  password: your_password
  from_name: "TinyForum"
```

## 感觉页面加载慢？

1. 检查 PostgreSQL 和 Redis 是否正常运行
2. 数据库连接池配置是否合理（`max_open_conns`）
3. 如果使用 LLM 敏感词复核，确保 Ollama 服务可达
4. 前端首次加载需 SSR 渲染，后续访问会更快
